pow​

pow(
    @base  ## required
    @exponent  ## required
) -> llll/null

Returns the value of @base to the power of @exponent.

Arguments​

  • @base [int/float/llll] Numeric llll.(required)
  • @exponent [int/float/llll] Numeric llll.(required)

Output​

Value of @base to the power of @exponent. [llll/null]

warning

pow is a built-in function in the bell programming language and is not unique or exclusive to bellplay~. As such, pow will return null without raising an error if required arguments are not provided.
