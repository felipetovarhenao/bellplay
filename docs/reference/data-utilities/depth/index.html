depth​

depth(
    @llll  ## required
) -> llll/null

Returns the depth of input llll.

Arguments​

  • @llll [llll] (required)

Output​

Depth of input llll. [llll/null]

warning

depth is a built-in function in the bell programming language and is not unique or exclusive to bellplay~. As such, depth will return null without raising an error if required arguments are not provided.
