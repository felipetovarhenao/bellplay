# Learn

:::tip Requirements
These materials assume basic familiarity with programming concepts such as variables, function calls, and loops. If you're new to the `bell` language, work through the [bell tutorials](https://felipetovarhenao.github.io/bell-tutorials/) first before proceeding with **bellplay~**-specific materials.
:::

The following **bellplay~** tutorials and examples are designed to be _plug-and-play_ learning and demonstration materials. To get the most out of them, you should:

1. **Run the code**: Each tutorial and example contains code snippets that can be copied with a single click and pasted into your text editor—preferrably [Visual Studio Code](/docs/installation/). Run the code in **bellplay~** to generate and hear the results.

2. **Study the code**: After running a script, examine it carefully:

   - Trace the sequence of buffer generation, transcription, and rendering.
   - Identify which **bellplay~** functions are being used and their parameters.
   - Note how buffers are created, processed, and placed on the timeline.
   - Observe the relationship between code structure and sound output.

3. **Read the docs**: For each **bellplay~** function encountered, consult its individual reference page. The function-specific documentation provides:

   - Description of what they do.
   - A detailed list of available arguments, default values, and expected data types.
   - Basic usage examples.

   Understanding each function's documentation is critical for an effective learning experience on how to use **bellplay~**.

4. **Experiment**: Modify the original scripts to test your understanding and explore possibilities:

   - Change parameter values and run the code to hear the differences.
   - Substitute different synthesis or processing functions.
   - Combine techniques and concepts from previous tutorials and examples.
   - Intentionally introduce errors to understand failure modes and error messages.

---

Active experimentation is when the actual learning occurs. These materials provide a foundation, but proficiency requires hands-on exploration.
